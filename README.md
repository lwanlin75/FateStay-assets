# FateStay-assets

## Character portraits

The `chars/` folder contains AI-generated, white-background anime portraits for the FateStay card. There are 615 independent portraits and 622 WebP file keys, including seven compatibility aliases.

`character-portraits.json` records character names, periods and variants, aliases, worldbook UIDs, image hashes, conditional gender selection and intentional omissions. Generic Fujimaru Ritsuka aliases require the current profile gender; male and female portraits remain separate from Ritsuka Suse.

Twelve targets without a sufficiently reliable usable appearance reference are left blank, along with one collective entry. Generation used original-work references where available. The manifest records the limits of independent reference checking for the earliest portraits; fine details can differ from the original artwork.
